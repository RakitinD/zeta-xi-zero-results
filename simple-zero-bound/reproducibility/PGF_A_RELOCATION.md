# PGF-A relocation mechanism

The frozen PGF-A replay script supports relocating the two original input archives.

Use:

`python replay.py --input-dir <directory-containing-the-two-original-input-zips>`

The default metadata stores absolute paths from the original workspace; that path dependence was
the hostile audit's K16 reproducibility defect. `--input-dir` is the existing relocation mechanism
and does not change the mathematical proof.
