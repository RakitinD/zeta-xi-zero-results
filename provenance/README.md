# Provenance

The git tree contains readable theorem statements, proofs, audit reports, and status documents.

Large frozen archives are distributed separately as GitHub Release assets. The Step-2 delivery
contains `release-assets/public-upload/` for the recommended `v0.1-frozen` upload set and a
separate third-party reference folder.

Exact SHA-256 pins are recorded in:
- `RELEASE_ASSET_HASHES.md`
- `GIT_TREE_HASHES_SHA256.txt`
